# Support Ticket Report

In this project, I worked with 40 customer support tickets. I created a program using JavaScript to check and analyze the ticket data. The program counts tickets by category and status, calculates the average resolution time in hours, and finds the agent who resolved the most tickets. It also checks which unresolved tickets have been open for more than 7 days. During this task, I handled incorrect or missing data, such as missing categories, invalid dates, and resolution dates that were earlier than the creation dates. The program skips these records and shows the reason for skipping them. I used three files for this project: `tickets.js` for the ticket data, `report.js` for the calculations, and `README.md` for the project information. To run the program, I opened the terminal in VS Code and used the command `node report.js`. This project helped me understand how to use JavaScript functions, work with dates, check data, and display results in the terminal.
